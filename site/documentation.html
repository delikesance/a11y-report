Documentation

Installez l'outil, générez un premier rapport, puis ajustez les options à votre client.

Installation

Prérequis : Node.js 22 ou plus.

npm install
npx playwright install chromium

Premier rapport

Passez une ou plusieurs URLs, le nom du client et celui de votre agence. Le PDF est écrit à l'emplacement de --out, et la progression s'affiche sur la sortie d'erreur.

node src/cli.js https://exemple.fr https://exemple.fr/contact \
  --client "Exemple SAS" \
  --agency "Mon Agence" \
  --color "#1d4ed8" \
  --contact "contact@agence.fr" \
  --out rapport-exemple.pdf

Pour un devis chiffré, ajoutez --taux (taux horaire HT), --telephone et --validite.

Options principales

Options les plus utilisées
Option Rôle
--client et --agencyNom du client et de l'agence (requis, sauf via --branding).
--logo, --colorLogo de l'agence et couleur principale du rapport.
--brandingCharge le branding depuis un fichier JSON ; les options en ligne de commande l'emportent.
--formatpdf (défaut), json, html, csv ou sarif, séparés par des virgules.
--viewportmobile, tablet, desktop ou LARGEURxHAUTEUR. Répétable.
--crawlExplore le site à partir de chaque URL, avec --crawl-depth, --max-pages, --exclude.
--save-json et --from-jsonSauvegarde un scan, puis génère un rapport sans relancer l'audit.
--concurrencyPages auditées en parallèle, de 1 à 16 (défaut : 1).

La liste complète s'affiche avec node src/cli.js --help.

Intégration continue

Le mode --ci n'affiche que le résumé des seuils et renvoie un code de sortie. Les seuils se donnent par option ou par fichier JSON.

node src/cli.js https://example.com --ci --seuil "critical=0,serious=5,score=80"
{ "critical": 0, "serious": 5, "moderate": 20, "score": 80, "unaudited": true }
Codes de sortie en mode CI
Code Signification
0Tous les seuils sont respectés.
1Erreur d'usage : option invalide, URL invalide, fichier de seuils illisible.
2Au moins un seuil est dépassé.
3Une page est non auditée et unaudited=true est demandé.

--ci-format github crée une annotation sur la pull request dans GitHub Actions ; --ci-format text (défaut) produit des lignes lisibles dans les journaux de GitLab CI.

Exemples complets : docs/ci/github-actions.yml et docs/ci/gitlab-ci.yml dans le dépôt. Ils supposent que Playwright et Chromium sont installés (npx playwright install --with-deps chromium) et que l'audit vise une URL de préproduction joignable depuis le runner.
