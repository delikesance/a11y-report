## Fiches par acteur

### Asqatasun (ex-Tanaguru)
- Forces : logiciel open source, automatisation forte, intégrable en CI via API (page officielle).
- Faiblesses : la page officielle ne décrit ni le RGAA ni les livrables ; la version courante n'est pas indiquée ; le support commercial de Tanaguru a disparu avec la faillite de 2014 (historique affiché).
- Livrables : non décrits sur la page consultée.
- Avis utilisateurs : non collectés.

### Temesis
- Offres affichées : accessibilité, écoconception, RGAA, formation (sous-domaine dédié, certification Qualiopi).
- Livrables : non précisés sur la page. Une plateforme est évoquée via un lien « Outils » sans détail.
- Prix : non public, passage par le contact.
- Avis utilisateurs : non collectés.

### Atalan
- Offres affichées : audit d'accessibilité, formation, sensibilisation au handicap, sites AcceDe Web et AcceDe PDF.
- Le RGAA n'est pas cité sur la page d'accueil. Les livrables ne sont pas décrits.
- Prix : non public ; devis gratuits et sans engagement.

### Access42
- Formation d'audit : programme de référence décrit dans un PDF (35 h, 5 jours, groupes de 5 à 8). Source non consultée directement : à vérifier.
- Prix : non public, devis après entretien de qualification (source tierce).
- Avis utilisateurs : non collectés.

### Opquast
- Forces : grille de prix publique la plus complète du corpus, formats variés (en ligne, inter, intra).
- Faiblesses : ce n'est pas un outil d'audit RGAA mais une formation qualité numérique.
- Livrables : certification, sessions de formation.

### Deque (axe)
- Origine : entreprise américaine, non française.
- Outils : extension axe DevTools gratuite (page consultée).
- Audit : pas de prestation d'audit décrite, « Request a quote or demo ».
- Formation : cours en ligne, formations en direct, préparation CPACC/WAS.
- Prix : non public.

### DINUM / Ara
- Le prix de référence de l'audit et les règles de marché public sont confirmés par la page DesignGouv.
- Ara : la page « Réaliser des audits d'accessibilité » n'a livré que son titre. Fonctionnalités (audit rapide 25 critères, rapport, déclaration) et gratuité : non vérifiées.
